# GuardLLM - Defensive Security Reverse Proxy for LLMs

GuardLLM is a high-performance, asynchronous defensive reverse proxy designed to inspect, sanitize, and audit LLM interactions in production environments.

## Objectives
- Mitigate OWASP Top 10 for LLMs (Prompt Injection, Sensitive Information Disclosure).
- Prevent PII leakage under LGPD & GDPR compliance.
- Structured security audit logging for SIEM integration.
